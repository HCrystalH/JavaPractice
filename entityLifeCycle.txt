Transient	New Java object, Hibernate doesn't know about it
Persistent	Associated with an active Hibernate Session
Detached	Was persistent, but no longer associated with a Session
Removed	    Scheduled for deletion

persist(): Move entity into Persistence Context
flush(): Synchronize Persistence Context -> Database
commit(): Commit Database Transaction

Session: Hibernate API/unit of work , it manage Persistence Context and
interact with DB through JDBC connection

Persistence Context: where Hibernate manage entity ( managed entity), it provides:
    + first-level cache
    + identity map
    + dirty checking
    + entity lifecycle management

Transaction: define boundary for atomic database operation

Database: where persistent data
